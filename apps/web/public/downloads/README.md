# CodeHero VS Code / Cursor extension

Baixe `codehero-vscode.vsix` no portal e instale:

1. Abra VS Code ou Cursor
2. Extensions → `…` → **Install from VSIX…**
3. Selecione o arquivo baixado
4. Abra um workspace e use **CodeHero: Scan Workspace** (ou salve um arquivo)

O scan é determinístico (sem IA por arquivo). Correções verificáveis via MCP SDD.
