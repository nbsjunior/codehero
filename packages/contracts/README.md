# @codehero/contracts

Contratos e catálogo de regras do CodeHero.

Catálogo de regras (L0, estruturais e análises COBOL), tipos compartilhados e a máscara léxica que separa código de comentário e de string.

Pacote de biblioteca: você normalmente quer [`@codehero/scanner`](https://www.npmjs.com/package/@codehero/scanner), que é a ferramenta de linha de comando.
