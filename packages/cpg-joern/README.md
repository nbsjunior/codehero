# @codehero/cpg-joern

Adaptador do CodeHero para o Joern.

Integração opcional com o [Joern](https://joern.io) (code property graph). **Degradável**: se o Joern não estiver instalado, o scan segue sem ele em vez de falhar.

Pacote de biblioteca: você normalmente quer [`@codehero/scanner`](https://www.npmjs.com/package/@codehero/scanner).
